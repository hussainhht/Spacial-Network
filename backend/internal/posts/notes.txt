endpoints - method - purpose :

.../posts       -> POST              -> create a new post
.../posts/{id}  -> GET               -> fetch a single post by id (private posts: 404 unless you're the owner)
.../posts/{id}  -> PUT or PATCH      -> edit a post (owner only, otherwise 403)
.../posts/{id}  -> DELETE            -> delete a post (owner only, otherwise 403)

notes:
- all routes are behind sessionMiddleware, so a valid session cookie is required (401 if missing/invalid).
- any other method on these paths gets an automatic 405 from the router (see internal/router/router.go).
